# Trading Edge Lab — مختبر الحافة التجارية

مشروع **Trading Edge Lab** هو نظام بحثي لاختبار استراتيجيات تداول العملات الرقمية (الكريبتو) بأمان، دون المخاطرة بأي أموال حقيقية.

## ماذا يفعل المشروع؟

- **الاختبار الرجعي (Backtesting):** إعادة تشغيل بيانات السوق التاريخية لقياس كيف كانت الاستراتيجية ستؤدّي في الماضي.
- **التداول الوهمي (Paper Trading):** محاكاة صفقات حية بأموال افتراضية لمراقبة سلوك الاستراتيجية في ظروف السوق الحقيقية دون تنفيذ أي أمر فعلي.

## ملاحظة مهمة

هذا المشروع **لا ينفّذ أي أوامر شراء أو بيع حقيقية** على أي بورصة، ولا يتصل بأي حسابات مالية حقيقية. إنه أداة بحث ومحاكاة فقط.
